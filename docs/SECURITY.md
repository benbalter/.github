# Security Policy

Please don't report security vulnerabilities in public issues.

Instead, report them privately using the **Report a vulnerability** button on the repository's **Security** tab ([GitHub private vulnerability reporting](https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)). If that isn't available for the repository, email [ben@balter.com](mailto:ben@balter.com).
